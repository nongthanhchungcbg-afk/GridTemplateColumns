# CSS Grid: `grid-template-columns`

Hai ví dụ trực quan về thuộc tính xác định số cột và kích thước track của Grid.

## Chạy và chụp ảnh

Mở `index.html` trong trình duyệt. Ví dụ A tạo 3 cột bằng nhau bằng `1fr 1fr 1fr`; ví dụ B tạo các cột `100px 200px 1fr`. Chụp màn hình khi cả hai ví dụ hiển thị để nộp bài.

## Ghi chú

`fr` chia phần không gian còn lại; `repeat(3, 1fr)` là cách viết gọn ba cột bằng nhau. Trên màn hình nhỏ, ví dụ B giảm kích thước cột cố định để tiếp tục vừa khung.
